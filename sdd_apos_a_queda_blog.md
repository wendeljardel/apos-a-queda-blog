# SDD — Projeto do Site “Após a Queda”

## 1. Visão Geral

### Nome do Projeto
Após a Queda

### Objetivo
Criar um site/blog minimalista, elegante e focado em ensaios teológicos, antropológicos e filosóficos sobre:
- pecado original;
- autoridade;
- abuso espiritual;
- consciência;
- relações humanas após a Queda;
- poder e dominação;
- espiritualidade cristã.

O site deve transmitir:
- profundidade;
- contemplação;
- sobriedade;
- clareza intelectual;
- permanência;
- simplicidade.

O objetivo NÃO é:
- viralização;
- conteúdo rápido;
- aparência corporativa;
- visual agressivo;
- experiência típica de rede social.

O site deve parecer:
- um caderno público de ensaios;
- uma biblioteca pessoal;
- um arquivo de pensamento em construção.

---

# 2. Filosofia de Design

## Princípios

### Minimalismo Radical
O texto é o centro da experiência.
Todo elemento visual deve servir à leitura.

### Long-form First
O site deve priorizar leitura longa e reflexão.

### Baixa Distração
Evitar:
- popups;
- banners;
- anúncios;
- excesso de animações;
- feeds infinitos;
- elementos chamativos.

### Atemporalidade
O design deve envelhecer bem por muitos anos.

### Velocidade
O site deve carregar extremamente rápido.

### Independência
O projeto deve ser:
- autocontrolado;
- facilmente hospedável;
- baseado em arquivos simples;
- sem dependência pesada de plataformas.

# 4. Estrutura do Site

### Home
Página principal minimalista.

- navegação simples.

- Abuso Espiritual
